### 👋 안녕하세요, 생각을 코드로 만들어가는 Cothink, 최승준 입니다.

**Java와 Spring을 중심으로 백엔드 개발**을 공부하고 있습니다.

단순히 기능을 구현하는 것에 그치지 않고, **왜 시스템을 이렇게 설계하는지**, 그리고 기술적인 선택이 어떤 문제를 해결하는지를 이해하는 개발자가 되고자 합니다.

현재 백엔드 엔지니어링과 데이터베이스 설계를 학습하고 있으며, AI를 개발과 학습에 효과적으로 활용하는 방법에도 관심을 가지고 있습니다.

### 💻 기술 스택

* **Backend** — Java, Spring, Spring Boot, JPA/Hibernate, MyBatis
* **Database** — Oracle Database
* **Frontend** — JSP, EL/JSTL, jQuery, Vue.js
